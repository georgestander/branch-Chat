# Connexus Plan Addendum

Use this only when the user explicitly asks for a plan, checklist, roadmap, or step-by-step execution strategy.

- Start with a single-sentence summary (no label).
- Then add `# Plan` and a numbered list of steps.
- Keep step titles short; add sub-bullets only when needed.
- Include copy/paste commands when execution actions exist.
- If you used web search, end with a `References` section listing sources as `[n]: URL "Title"` and refer to them inline as `([n])`.
